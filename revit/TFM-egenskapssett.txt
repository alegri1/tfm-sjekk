#
# Egenskapssett for TFM ved IFC-eksport fra Revit.
#
# Uten en fil som denne tar Revits IFC-eksportør bare med sine egne
# standard-psett. TFM-parameteren blir da liggende igjen i modellen, og
# eksporten inneholder ingen TFM i det hele tatt — verktøyet melder K1 på
# hvert eneste objekt. Det er prøvd: en eksport med standardoppsett ga
# åtte K1-feil på åtte objekter.
#
# Slik tas den i bruk i Revit 2027:
#     File > Export > IFC > Edit setup
#     > fanen «Parameter Mapping»
#     > kryss av «Export user defined property sets»
#     > filvalget dukker først opp ETTER avkryssingen — pek på denne fila
#
# Merk at fanen ikke heter «Property Sets» lenger. Den het det i eldre
# versjoner; i 2027 er innholdet delt i Category Mapping, Property Mapping og
# Parameter Mapping, og det er den siste som gjelder her.
#
# PRØVD 2026-08-21 i Revit 2027. Eksporten fikk da:
#     [TFM11_Forekomst]  TFM        8 objekter
#     [TFM11_Type]       TFMType    2 objekter
#     [MMI]              MMI        8 objekter
# altså nøyaktig navnene standardoppsettet i tfm-sjekk.toml leter etter.
# Uten fila ga samme modell åtte K1-feil på åtte merkede objekter.
#
# Formatet er Autodesks eget, dokumentert i
# AddIns\IFCExporterUI\DefaultUserDefinedParameterSets.txt:
#
#     PropertySet:<tab><navn><tab>I eller T<tab><IFC-klasser, komma>
#     <tab><egenskapsnavn><tab><datatype><tab><Revit-parameter om ulikt>
#
# VIKTIG: kolonnene skilles med TABULATOR, ikke mellomrom. Er de skilt med
# mellomrom, leses fila uten feilmelding og uten virkning.
#
# Navnet til høyre er Revit-parameteren. Heter den noe annet hos dere,
# er det den kolonnen som skal endres — ikke de to første.
#

PropertySet:	TFM11_Forekomst	I	IfcDistributionElement,IfcFlowTerminal,IfcFlowController,IfcFlowMovingDevice,IfcFlowSegment,IfcFlowFitting,IfcEnergyConversionDevice,IfcDistributionControlElement,IfcElectricDistributionPoint,IfcBuildingElementProxy
	TFM	Text	TFM

PropertySet:	TFM11_Type	I	IfcDistributionElement,IfcFlowTerminal,IfcFlowController,IfcFlowMovingDevice,IfcFlowSegment,IfcFlowFitting,IfcEnergyConversionDevice,IfcDistributionControlElement,IfcElectricDistributionPoint,IfcBuildingElementProxy
	TFMType	Text	TFM11_Type.TFMType

PropertySet:	MMI	I	IfcDistributionElement,IfcFlowTerminal,IfcFlowController,IfcFlowMovingDevice,IfcFlowSegment,IfcFlowFitting,IfcEnergyConversionDevice,IfcDistributionControlElement,IfcElectricDistributionPoint,IfcBuildingElementProxy
	MMI	Text	MMI.MMI
